# TBA

Your music scene, in feeds you choose: follow bands, venues and fanclubs, see upcoming gigs and releases, and see which friends are going. Chronological, no algorithm. Built on [atproto](https://atproto.com), with Bluesky login.

## Docs

- [Architecture](docs/architecture.md): how it's built and why
- [Lexicons](packages/lexicons/README.md): record formats and trust rules
- [AGENTS.md](AGENTS.md): rules for contributors and coding agents

## Data sources & thanks

Thank you to **[MusicBrainz](https://musicbrainz.org)** and the [MetaBrainz Foundation](https://metabrainz.org). Unclaimed band entries are seeded from MusicBrainz artist data, and [our genre vocabulary](packages/lexicons/vocab/genres.json) started as a copy of the [MusicBrainz genre list](https://musicbrainz.org/genres). Both are CC0 [core data](https://musicbrainz.org/doc/About/Data_License). If TBA helps you, consider [supporting MusicBrainz](https://metabrainz.org/donate).

Gig listings are copied by hand from venues' public calendars, each with its source.
